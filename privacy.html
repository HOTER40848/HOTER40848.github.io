개인정보처리방침

시행일: 2026년 11월 9일

본 방침은 YouTube Analytics Master(이하 '도구')가 Google 사용자 데이터에 접근하고 이를 처리하는 방식을 설명합니다. 이 도구는 개인 유튜브 채널 운영자의 통계 관리용으로 설계되었습니다.

1. 접근하는 데이터

  • 승인된 YouTube 채널 및 업로드 영상의 식별자, 제목, 게시일, 공개 상태 등 메타데이터
  • YouTube Analytics 및 Reporting에서 제공하는 조회수, 시청 시간, 구독자 변화, 트래픽 소스, 노출·도달, 검색어, 자막·기기, 집계된 시청자 특성 및 시청 유지율
  • 분석 결과를 기록·갱신하기 위한 Google Sheets 문서와 관련 실행 상태 정보

제공되는 데이터의 종류와 범위는 Google 계정 소유자가 승인한 OAuth 권한 및 각 API가 반환하는 정보에 따라 달라집니다.

2. 이용 목적

위 데이터는 승인된 개인 채널의 성과 분석, 일별·주별 통계 정리, 오류 감시, 누락 데이터 재수집 및 시트 기록을 위해 사용합니다. 광고 타기팅, 사용자 프로파일 판매 또는 별도의 공개 분석 서비스 제공을 목적으로 사용하지 않습니다.

3. 저장·접근 및 공유

수집된 분석 결과는 주로 계정 소유자가 관리하는 Google Sheets와 관련 Google Apps Script 설정·실행 기록에 저장됩니다. 사이트 자체(GitHub Pages)는 방문자의 Google 계정 로그인을 받거나 OAuth 토큰을 수집하지 않습니다.

운영자는 데이터를 판매하지 않습니다. 처리에 필요한 Google 서비스와 계정 소유자가 직접 권한을 부여한 연동 도구 또는 공동 작업자를 통해 데이터에 접근할 수 있으며, 이 경우 각 서비스의 접근 권한 및 정책이 적용됩니다.

Google 사용자 데이터의 사용과 이전은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

4. 보유 기간 및 삭제

데이터는 채널 통계 운영과 장기 변화 분석에 필요한 기간 동안 저장되며, 운영자가 관리하는 Google Sheets 및 Apps Script 프로젝트에서 삭제할 수 있습니다. 계정 소유자는 Google 계정 연결 관리를 통해 접근 권한을 철회할 수 있습니다. 승인 철회 시 해당 권한으로 수집·보관한 YouTube 승인 데이터는 YouTube API 정책에 따라 가능한 한 신속히, 늦어도 7일 이내에 삭제해야 합니다.

데이터 삭제·문의는 아래 연락처로 요청할 수 있습니다. Google 또는 GitHub가 자체적으로 보관하는 서비스 운영 기록에는 각 제공자의 정책이 적용됩니다.

5. 제3자 서비스 및 보안

도구는 Google Apps Script, YouTube API 서비스 및 Google Sheets를 사용하며, 이 안내 웹사이트는 GitHub Pages에 호스팅됩니다. GitHub는 사이트 접속 시 보안 목적의 접속 기록을 처리할 수 있습니다. 도구의 운영 권한은 계정 소유자가 관리하고, 접근 권한을 필요 범위로 제한하도록 노력합니다.
